## About

This repository documents my journey through the **Complete Intro to React, v9** on Frontend Masters. The course builds a strong foundation in React by exploring components, props, state, hooks, and modern rendering patterns.

### Project Context

**Purpose**: Build production-ready React applications from first principles  
**Scope**: Full course curriculum including exercises and the capstone app  
**Instructor**: [Brian Holt](https://frontendmasters.com/teachers/brian-holt/)

This repository serves as a hands-on laboratory for understanding React’s rendering model, component composition, and state-driven UI architecture.

---

## Key Learnings

Throughout this course, I implemented:

- **Component Architecture**: Building reusable UI using functional components.
- **Props & Data Flow**: Managing one-way data flow between components.
- **State Management**: Handling dynamic UI updates with `useState`.
- **Side Effects**: Fetching and synchronizing API data with `useEffect`.
- **Routing**: Implementing client-side navigation with React Router.
- **Modern Tooling**: Developing with Vite for fast builds and HMR.
- **React Internals**: Understanding reconciliation and the virtual DOM.
